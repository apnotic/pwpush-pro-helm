# Security Policy

This page outlines the general procedure for reporting security vulnerabilities.

All reports (and the time you spend to discover them) are very much appreciated.

## Supported Versions

We support security reports for the latest minor version of the Helm chart.

## Reporting a Vulnerability

Please use the GitHub [Report a vulnerability](https://github.com/apnotic/pwpush-pro-helm/security/advisories/new) feature.

_We kindly ask you to not report any potential vulnerabilities publicly as it may put existing users at risk. Your help in this is greatly appreciated!_

## Scope

This security policy covers the Helm chart templates and configuration in this repository. For security issues related to the Password Pusher Pro application itself, please report to the [Password Pusher security policy](https://github.com/pglombardo/PasswordPusher/security/policy).
