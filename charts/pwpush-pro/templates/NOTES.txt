2. CRITICAL - Back up your encryption secrets:

  kubectl get secret {{ include "pwpush-pro.secretName" . }} -n {{ .Release.Namespace }} -o yaml > pwpush-pro-secrets-backup.yaml

  Store this file securely. If you lose these keys, all encrypted data
  becomes permanently inaccessible.
